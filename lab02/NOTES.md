Рабочая папка - это папка на компьютере, где мы редактируем и видим файлы 
Индес - это корзина для подготовки к сохранению.
Коммит - это точка сохранения  проекта.
git - консольная утилита, которая на локальном устройстве
github - сайт, созданный для размещение проектов
git diff сравнивает рабочую директорию и индекс
git diff --staged сравнивает индекс и последний коммит 
Использованные команды 
git status - показывает текущее состояние рабочей директории
git diff - показыввает разницу между рабочей директорией и индексом 
git diff --staged - показывает разницу между индексом и последним коммитом
